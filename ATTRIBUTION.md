# Attribution and project evolution

This project was developed as a learning extension of the public educational single-stock VaR project shared by the user:

`https://github.com/in2thedrift/stock-var-app/tree/main/stock-var-app/stock-var-app`

The original project provided the single-security learning architecture, including market-data access, Streamlit presentation, Monte Carlo / Historical / Parametric VaR comparison and VaR/CVaR concepts.

The portfolio version adds substantial new work around:

- multi-asset holdings and weight validation
- aligned portfolio market data
- covariance and correlation
- correlated multivariate simulation
- joint historical bootstrap
- portfolio VaR/CVaR
- risk contribution
- diversification diagnostics
- mixed-currency controls
- data-quality / provenance reporting
- portfolio-specific methodology and tests

The source project was distributed under the MIT License. The included `LICENSE` file is retained with this derivative educational work.

When discussing the project, describe it accurately as an **adaptation / extension**, not as a completely original codebase written from scratch.
